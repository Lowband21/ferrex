The operator guide is the home for running Ferrex safely. It prioritizes configuration, user data, recovery paths, and observable service behavior over implementation internals.

## Recovery-first rule

Any operator-facing change should document how to retry, reset, or recover without deleting more data than intended. Android and Android TV recovery guidance in the QA reference is especially strict: data-wipe-class problems should be treated as release blockers until a no-wipe exit exists.
