## Canonical files intentionally not migrated

- `.github/CONTRIBUTING.md`, `.github/SECURITY.md`, `.github/TRADEMARKS.md`, and `.github/CODE_OF_CONDUCT.md` remain canonical GitHub policy files. See [Project policies](/reference/project-policies/).
- Crate/package READMEs remain canonical at package paths. See [Crate README inventory](/reference/crate-readmes/).
- `docs/bench_results/*.json` remain benchmark data artifacts and are not rendered as guide pages.
