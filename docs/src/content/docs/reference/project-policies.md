## Security policy

Ferrex vulnerabilities should be reported privately through GitHub Security Advisories when available or through the maintainer's GitHub profile. Do not open public issues for vulnerabilities.

## Contribution workflow

Use the canonical [Contributing guide](https://github.com/Lowband21/ferrex/blob/dev/.github/CONTRIBUTING.md) for local setup, hooks, checks, and pull-request expectations. Detailed workflow pages in this docs site point back to that file when GitHub-facing contribution policy is the source of truth.
